About Clyvora

Useful tools with a clear privacy boundary.

Clyvora—also known as Clyvora Tech or Clyvora Technologies—is an independent open-source software project creating focused browser tools for data and media.

What Clyvora builds

Clyvora tools are designed to work without accounts, cloud libraries, advertising, or behavioural analytics. Selected files are parsed and transformed locally in the browser, so they are not uploaded to a Clyvora processing or conversion server.

The projects are published as open-source software so people can inspect how the tools work, report problems, and contribute improvements.
